
### [GREEN] OpenClaw Cron-Free Scheduler
**Category:** OpenClaw Workflow and Automation
**Risk Level:** green
**Confidence:** High

**Description:**
A built-in scheduling system for OpenClaw that runs time-based triggers without relying on the host's cron daemon. It uses a persistent process with setTimeout loops and a job store (SQLite) to maintain schedules across restarts. Provides the same cron-like capabilities (every N minutes, at specific times) with self-healing (auto-restart on reboot, detect missed jobs). This eliminates dependency on system cron, ensuring OpenClaw skills always execute on time even in containerized or restricted environments.

**Rationale:**
The current hosting environment lacks a functioning cron service, causing all scheduled automation (including the daily work form submission and autonomous ideation) to fail. The OpenClaw System Sentinel can monitor but not fix this underlying reliability issue. A self-contained scheduler would make OpenClaw truly autonomous and portable, removing a single point of failure.

**Implementation Tasks:**
- Design job store schema: store skill triggers (cron expressions or intervals), last run timestamps, next run calculations
- Build a scheduler engine that runs as a long-lived OpenClaw plugin: on startup, load jobs, compute next run times, set timeouts; on each execution, reschedule
- Implement reliability features: catch unhandled exceptions, log failures, retry with backoff, detect missed jobs after restart and run them if within threshold
- Create migration path: convert existing crontab entries to OpenClaw jobs automatically (parse user's crontab and generate job definitions)
- Update skills to register their cron jobs via OpenClaw API instead of relying on system crontab; provide fallback to system cron if available
- Test thoroughly: simulate restarts, clock changes, long-running jobs; verify no overlaps
- Deploy as a core OpenClaw plugin, document setup

### [YELLOW] Personal Social Media Analytics & Growth Dashboard
**Category:** Research & Intelligence
**Risk Level:** yellow
**Confidence:** High

**Description:**
A unified dashboard that aggregates analytics from Master's social accounts (Twitter, LinkedIn, Instagram) to track follower growth, engagement rates, top-performing content, and audience demographics. It uses AI to identify content patterns that drive engagement, suggests optimal posting times, and highlights content gaps. Provides actionable insights to grow personal brand and monetization potential.

**Rationale:**
As a corporate trainer and Web3 enthusiast, Master needs to maintain a strong online presence. Manually checking analytics across platforms is time-consuming and fragmented. This tool centralizes data, surfaces insights, and helps Master focus on content that resonates, accelerating brand growth and opening revenue streams (e.g., sponsorships, course sales). It complements the planned Social Media Publisher by closing the feedback loop.

**Implementation Tasks:**
- Integrate with Twitter API (v2), LinkedIn API, Instagram Basic Display to fetch posts and metrics (impressions, engagements, follower count)
- Build data aggregation pipeline: normalize metrics, store in time-series DB (e.g., InfluxDB or SQLite)
- Develop AI analyzer: cluster posts by topic, format, time; correlate with engagement to identify winning patterns; predict best posting times
- Create dashboard UI (React) with charts: follower growth, engagement trends, top posts, audience demographics (if available)
- Add insights generator: weekly digest with key takeaways, content ideas, and recommended actions
- Implement alerts: sudden drops in engagement, follower spikes, competitor moves (optional)
- Ensure privacy: data stored locally; API keys secured; no external sharing
