**Description:**

Master maintains multiple OpenClaw skills and applies strict documentation standards (as codified in MEMORY.md). Manually crafting each README is tedious and risks inconsistency. - Create a Jinja2 or mustache template matching the standard README structure defined in the GitHub Documentation Standardization Protocol.

- Add a `make readme` or npm script to each skill repo; optionally integrate into a pre-commit hook.
- Test on existing skills (ms-forms-auto, knowledge-management, etc.) and refine template based on feedback.
