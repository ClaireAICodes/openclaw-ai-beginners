### [GREEN] OpenClaw System Sentinel
**Category:** OpenClaw Workflow and Automation
**Risk Level:** green
**Confidence:** High

**Description:**
A lightweight monitoring agent that continuously checks the health of the OpenClaw system: cron job presence, skill execution logs for failures, credential expiration warnings, and disk space. It sends Telegram alerts for anomalies and can auto-recover from common failure patterns (e.g., reinstall missing cron, trigger credential refresh prompts).

**Rationale:**
The autonomous system recently suffered a 9-day silent outage due to missing cron jobs. Without active monitoring, failures go unnoticed until Master encounters broken workflows. A sentinel provides proactive reliability, reduces downtime, and maintains the self-running nature of the ecosystem. It's an internal tool that protects all other automations.

**Implementation Tasks:**
- Define health checks: crontab entries, recent log activity, auth state validity, storage thresholds
- Build a polling script (runs hourly via cron) that collects metrics and compares to baselines
- Create alert logic: send Telegram message when issues detected (critical vs warning)
- Implement safe auto-recovery actions: e.g., if cron missing → run setup-cron.js; if auth expired → send reminder to re-auth
- Store health history in a simple SQLite DB for trend analysis
- Integrate with existing OpenClaw gateway status checks

### [YELLOW] YouTube Alpha Picker for Crypto/Trading
**Category:** Research & Intelligence
**Risk Level:** yellow
**Confidence:** High

**Description:**
An autonomous agent that scans YouTube for new videos from trusted crypto/trading channels, fetches transcripts or audio, uses AI to extract trade ideas, market sentiment, and potential alpha signals. It produces a daily digest highlighting concrete opportunities (e.g., "3 analysts bullish on SOL ahead of breakout") with confidence scores and links.

**Rationale:**
Master consumes YouTube for market intelligence but lacks time to watch hours of content. This tool filters noise, surfaces actionable insights from reputable creators, and synthesizes signals into a quick-read report. It taps into a rich information source that's not captured by traditional on-chain or price APIs, giving a qualitative edge.

**Implementation Tasks:**
- Compile list of target YouTube channels (e.g., Coin Bureau, To The Moon, Crypto Anarchy)
- Use YouTube Data API to fetch latest videos by channel (filter by publish date)
- For each video, download transcript (or audio for Whisper transcription) using yt-dlp
- Run StepFun analysis: extract trade setups, key price levels, sentiment, timeline, and confidence
- Apply credibility weighting based on historical accuracy (track predictions vs outcomes)
- Generate daily markdown digest with top 5 insights, videos linked, and executive summary
- Deliver to Telegram or store in a designated folder
