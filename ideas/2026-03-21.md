### [GREEN] Automated Backup & Integrity Checker
**Category:** OpenClaw Workflow / Research & Intelligence
**Risk Level:** green
**Confidence:** High

**Description:**

A cron-driven system that scans critical directories (memory files, skill repos, blog posts, config files) for changes, creates timestamped snapshots, and verifies integrity using checksums. Detects accidental deletions or corruption, and can restore previous versions. Provides a weekly summary of backup status and alerts on failures.

**Rationale:**
Master's work is valuable and spread across many files. Manual backups are error-prone. This automated system ensures no data loss and provides peace of mind. It's a low-maintenance, high-reliability safety net that runs in the background. Especially important as he builds more skills and projects; losing memory files or skill code would be a significant setback.

**Implementation Tasks:**
- Identify critical paths: workspace root, memory files, skill directories, config
- Implement snapshot creation: tar/gzip with timestamps, exclude temp/cache
- Compute and store checksums (SHA256) for each snapshot and key files
- Retention policy: keep last 30 days, purge older automatically
- Integrity verification: weekly scan comparing checksums, alert on mismatches
- Restore script: easy one-command recovery to a given date
- Status reporting: weekly markdown summary with backup count, disk usage, any issues
- Cron setup: daily snapshots at 2 AM SGT, weekly verification Sunday 3 AM
