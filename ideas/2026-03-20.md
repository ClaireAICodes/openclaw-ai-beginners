### [YELLOW] Unified Knowledge Base with Intelligent Search
**Category:** Research & Intelligence / OpenClaw Workflow
**Risk Level:** yellow
**Confidence:** High

**Description:**

A centralized knowledge repository that indexes all of Master's digital assets: memory files, saved articles, code snippets, GitHub repos, bookmarks, PDFs, and notes. Provides AI-powered semantic search with natural language queries like "Show me research on NFT liquidity from last month" or "Find my Flutter gym app design notes." Supports tags, backlinks, and automatic categorization. Accessible via web UI and CLI, with optional obsidian-like bidirectional linking.

**Rationale:**
Master accumulates information across many platforms and formats - memory files, browser bookmarks, GitHub repos, PDFs, YouTube videos, Discord chats. Retrieval is scattered and often relies on manual recall. A unified knowledge base with intelligent search transforms this chaos into a coherent, searchable corpus. It becomes his "second brain," allowing instant access to any past insight, research, or note. This directly addresses his need for efficiency and unique edges by making accumulated knowledge instantly actionable.

**Implementation Tasks:**
- Ingestion pipeline: crawlers for local files (markdown, PDFs, images), GitHub API for repos, browser bookmark export, YouTube watch history
- Indexing engine: use vector embeddings for semantic search (local model or lightweight API)
- Web UI: clean interface with search bar, faceted filters (date, type, tags), and result previews
- CLI tool: `kb search "NFT liquidity solutions"` for terminal-based access
- Auto-tagging: LLM suggests tags and categories during ingestion, learns from manual corrections
- Backlink system: detect and display bidirectional links between related documents (like Obsidian)
