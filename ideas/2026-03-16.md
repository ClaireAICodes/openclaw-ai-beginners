### [GREEN] Web3 Alpha Hunter & Narrative Shift Detector
**Category:** Research & Intelligence / Web3 & Crypto
**Risk Level:** green
**Confidence:** High

**Description:**
An automated research system that scans for emerging opportunities before they trend. It monitors GitHub repos (stars, commits, contributor growth), on-chain metrics (new contract deployments, whale wallet movements, unusual token flows), social signals (crypto Twitter sentiment shifts, Discord/Telegram buzz), and VC funding announcements. It surfaces early-stage protocols, narrative shifts (e.g., "DePIN is heating up"), and actionable alpha with confidence scores and reasoning. Delivers a daily "Alpha Brief" via Telegram.

**Rationale:**
Master's biggest pain point is "need for inspiration, unique edges, and insights he wouldn't think of." Existing trading signal tools track known assets, but none hunt for *emerging* opportunities. Getting in early on trends (before mainstream coverage) is the highest-leverage edge in crypto. This tool automates what VCs and professional researchers do manually — scanning hundreds of sources to find signal in noise — and delivers it to Master before breakfast.

**Implementation Tasks:**
- GitHub scanner: monitor crypto-related repos for star velocity (>50/day), commit frequency spikes, and new contributor surges; flag repos matching trending narratives (AI+crypto, DePIN, restaking)
- On-chain watcher: track new token deployments on Ethereum/Solana/Base; monitor whale wallets (top 100 tracked addresses) for accumulation patterns; detect unusual bridging activity between chains
- Social sentiment engine: sample crypto Twitter lists and trending hashtags; use LLM to classify emerging narratives vs. noise; track sentiment velocity (how fast a topic is gaining mentions)
- VC funding tracker: parse announcements from Messari, The Block, Defiant; flag rounds >$5M in sectors Master cares about
- Alpha brief generator: compile top 5 emerging opportunities with: what it is, why it matters, evidence (on-chain + social), risk assessment, and suggested watchlist actions
- Telegram delivery: send daily brief at 7:30 AM SGT; include one-tap commands to add protocols to watchlist or dismiss

### [GREEN] Cross-Domain Knowledge Graph for Passive Income Research
**Category:** Research & Intelligence / OpenClaw Workflow
**Risk Level:** green
**Confidence:** High

**Description:**
Build a local knowledge graph (using markdown + JSON index) that connects insights across Master's three major domains: corporate training, Web3/crypto, and content/blog creation. The system cross-references blog topics with market trends, training methodologies with automation opportunities, and crypto narratives with content angles. When a new crypto trend emerges, it automatically suggests blog post angles and potential training course topics. When a training insight is logged, it checks for relevant crypto/business applications. The graph grows with each heartbeat, creating a compounding knowledge asset.

**Rationale:**
Master's pain points include "need for inspiration, unique edges, and insights he wouldn't think of." Currently his blog posts (daily via Paragraph), crypto research, and training career operate in silos. A cross-domain knowledge graph surfaces non-obvious connections — e.g., "your blog on AI security could tie into the new DePIN narrative" — that create compound value. This is the kind of multi-dimensional thinking that takes humans hours but a well-structured system can generate in seconds. It directly addresses passive income by turning existing content into a self-reinforcing research engine.

**Implementation Tasks:**
- Design markdown-based knowledge graph schema: entities (concepts, projects, people), relationships (influences, contradicts, enables), and domain tags (training, web3, content)
- Build index script that parses existing blog posts, memory files, and ideas to extract entities and relationships
- Create cross-reference engine: given a new crypto trend, search training concepts and blog history for relevant connections; output "bridge ideas" with rationale
- Add auto-tagging to daily blog post generator: extract key concepts and link them to the knowledge graph
- Generate weekly "Connection Report" highlighting non-obvious cross-domain insights Master might leverage

### [GREEN] Smart Calendar Event Parser from Email HTML
**Category:** Apps & Code / OpenClaw Workflow
**Risk Level:** green
**Confidence:** High

**Description:**
Build an automated system that parses Master's Microsoft 365 inbox for HTML-formatted class/event information emails from his boss, extracts event details (date, time, location, class name, attendees), and automatically creates calendar invites or reminders. The parser handles the inconsistent HTML formats his boss uses, normalizes the data, and either creates proper calendar events or sends Master a quick-approve notification via Telegram with pre-filled event details.

**Rationale:**
Directly from USER.md: "Email inbox management" and "Calendar syncing (boss sends class info via HTML email without calendar invites)" are explicitly listed as automation targets. This is a recurring, time-consuming pain point — Master has to manually read HTML emails, extract details, and create calendar entries. Automating this saves daily friction and prevents missed classes or double-bookings. It's also a concrete, buildable project that demonstrates immediate value from the OpenClaw setup.

**Implementation Tasks:**
- Build HTML email parser that identifies class/event information emails (pattern-match sender, subject keywords like "class", "schedule", "training")
- Extract structured data from varied HTML formats: dates, times, venue names, class titles, participant lists
- Create normalization layer to handle date format variations and ambiguous time references
- Build Telegram approval flow: send parsed event as a one-tap "Add to Calendar" notification with preview
- Add fallback: if parsing confidence is low, forward the raw email to Master with a "Needs manual review" flag
- Track parsing accuracy and learn from corrections to improve over time
