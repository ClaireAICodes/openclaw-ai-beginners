### [GREEN] OpenClaw Health Monitor & Auto-Recovery System
**Category:** OpenClaw Workflow and Automation
**Risk Level:** green
**Confidence:** High

**Description:**
A lightweight monitoring system that proactively checks the health of critical OpenClaw operations (cron jobs, backups, agent status) and automatically attempts recovery when failures are detected. This addresses the recent backup failure and prevents silent degradation of automation infrastructure.

**Rationale:**
Yesterday's backup failure (SIGTERM timeout) was only noticed via manual review. Master relies on OpenClaw to run autonomously, but silent failures can accumulate and cause data loss, missed deliveries, and workflow disruptions. A health monitor would serve as an early warning system and self-healing mechanism, reducing the need for manual oversight and increasing reliability of the entire automation ecosystem.

**Implementation Tasks:**
- Create health-check script (`scripts/health-monitor.js`) that runs every 30 minutes via cron
- Monitor: cron job status (check last run times), log error patterns, disk space, recent backups
- Implement auto-recovery for known issues: retry failed backups with exponential backoff, restart stalled agents
- Send Telegram alerts with severity levels and recovery actions taken
- Open dashboard endpoint (localhost:PORT/health) for quick status overview
- Add health state persistence to track trends over time

### [YELLOW] Passive Income Opportunity Scout v0.1
**Category:** Passive Income & Businesses
**Risk Level:** yellow
**Confidence:** High

**Description:**
An automated research assistant that continuously scouts and scores passive income opportunities tailored to Master's profile: AI/automation expertise, Web3 interest, trading background, and ability to build micro-SaaS tools. It aggregates opportunities from niche forums, GitHub trending, product hunt, and Web3 platforms, then ranks them by effort/reward ratio and alignment.

**Rationale:**
Master explicitly wants passive income streams ("money while sleeping") but lacks time to research opportunities systematically. Manual browsing is inefficient and misses hidden gems. An automated scout would provide a steady pipeline of vetted, actionable ideas that match his skills and interests, accelerating the path to automated revenue without requiring significant time investment.

**Implementation Tasks:**
- Build scraper/aggregator modules: GitHub trending (AI/automation), Product Hunt launches, Web3/NFT forums, micro-SaaS platforms
- Create scoring algorithm based on: development effort estimate, maintenance burden, market size, monetization potential, alignment with Master's skills
- Build simple filter UI (local web page) to browse and deep-dive into opportunities
- Set up weekly digest email (or Telegram message) with top 5 opportunities and brief analysis
- Include "starter pack" for each opportunity: required skills, time estimate, competitive landscape notes
- Track opportunity lifecycle: Scouted → Researched → Building → Launched → Scaling
