### [GREEN] Cryptocurrency Portfolio Dashboard
**Category:** Trading & Investment
**Risk Level:** green
**Confidence:** High

**Description:**
A dashboard that aggregates cryptocurrency holdings across multiple wallets and exchanges, displaying net worth, asset allocation, and performance metrics. Integrates with blockchain APIs (Etherscan, BSCScan, Solana) and exchange APIs (Binance, Coinbase) to fetch balances in real-time. Supports historical value tracking, profit/loss calculations, and customizable alerts for significant changes. All data stored locally for privacy.

**Rationale:**
Master is active in crypto and needs a clear, consolidated view of his portfolio without manual spreadsheets. An automated dashboard provides instant insights into asset distribution, gains/losses, and overall net worth, helping him make informed investment decisions and track performance across tokens. It's a foundational tool for managing a diverse crypto portfolio.

**Implementation Tasks:**
- Build a fetcher that securely reads API keys for exchanges and blockchain explorers (config stored locally, never shared)
- Create a unified data model: wallet addresses, exchange connections, token metadata (symbol, price, decimals)
- Implement balance aggregation: query each source, normalize to common base currency (USD) via price APIs (CoinGecko)
- Store historical snapshots in SQLite to compute P&L over time and generate charts
- Develop a simple web dashboard (or terminal UI) displaying net worth, allocation pie chart, top gainers/losers, and recent transactions
- Add alerting: optional Telegram notifications for price movements or large balance changes
- Ensure privacy: all data stored locally; no external servers; optional encryption at rest
- Write clear documentation for adding new exchanges and custom tokens

### [GREEN] Incremental & Compressed Backup System
**Category:** OpenClaw Workflow and Automation
**Risk Level:** green
**Confidence:** High

**Description:**
A backup system that uses file-level deduplication and compression to only transfer changed data to Google Drive. It computes hashes of files to detect modifications, creates compressed archives of changed files grouped by date, and maintains a local manifest for fast restoration. By default, excludes large, unnecessary directories (node_modules, .git/objects, build/) to minimize size. Runs efficiently within minutes instead of hours.

**Rationale:**
The current daily backup uploads all files unconditionally, including massive node_modules, leading to extremely long runtimes (observed 50+ minutes for partial backup) and incomplete transfers. An incremental approach drastically reduces transfer volume, ensures backups complete reliably, and respects bandwidth limits. This directly improves system reliability and ensures Master always has a valid restore point.

**Implementation Tasks:**
- Add a configuration layer for exclusion patterns (default excludes: node_modules/, .git/objects, .git/refs, dist/, build/, coverage/, .cache/)
- Implement a scanner that walks all source directories, computing SHA256 for each file (caching previously seen hashes)
- Compare against the last backup manifest to identify new/modified files
- Group changed files into a single compressed tar.zst archive named with timestamp and manifest
- Upload archive to a dated folder on Drive; also upload manifest separately
- Write a restore script that reads manifest and extracts needed files from archives
- Add progress logging and Telegram alerts for failures or unusually large change sets
- Modify the daily cron to use the new incremental backup script

### [GREEN] AI-Powered Training Content Repurposer
**Category:** Work & Career
**Risk Level:** green
**Confidence:** High

**Description:**
A tool that transforms YouTube videos (e.g., industry talks, tutorials, interviews) into complete training materials: structured slide decks, handouts, quiz questions, and speaker notes. It downloads transcripts, uses LLMs to extract key concepts, rephrase for clarity, generate examples, and format outputs into branded templates. Integrates with Google Slides or PowerPoint for one-click deck generation. Supports Master's own videos as well for repurposing into micro-content.

**Rationale:**
As a corporate trainer, Master constantly needs to develop workshop materials. Instead of starting from scratch, he could leverage existing high-quality YouTube content as a base and rapidly convert it into polished training packages. This saves hours of research and slide creation, accelerates content development, and allows him to focus on delivery and customization. It also opens a potential product line: selling ready-made training kits.

**Implementation Tasks:**
- Build a fetcher that accepts a YouTube URL, retrieves transcript (via youtube-transcript API or Whisper if needed)
- Process transcript with LLM: identify learning objectives, segment into modules, extract key takeaways, generate discussion questions and quiz items
- Apply a template system: map structured content into Google Slides via Slides API or generate a PowerPoint file with consistent branding
- Produce supplementary documents: handout summaries (markdown/PDF), speaker notes with timing cues, and a facilitator guide
- Add a batch mode: process playlists to create entire course materials in one run
- Include a review UI where Master can approve, edit, or regenerate sections before final export
- Store processed videos locally to avoid re-downloading; maintain a library of available content sources
- Support Master's own videos (if he records training sessions) to generate blog posts, social snippets, and email courses
