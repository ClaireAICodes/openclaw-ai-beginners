**Architectural Innovations:**
- Semantic Snapshots reduce token costs by 90% (50KB vs 5MB screenshots)
- Lane Queue system prevents race conditions through serial execution
- Local-first Gateway with multi-agent routing isolation
- "Lobster" workflow shell for automatic skill chaining

**Security Critical Insights:**
- Lethal trifecta: private data access + untrusted content exposure + action authority
- Prompt injection bypasses prompt-only guards—architectural boundaries required
- Persistent memory across sessions creates irreversible risk if misconfigured
- Falcon AIDR guardrails successfully blocked malicious injection in tests

**Crypto/Trading Automation Maturity:**
- Proven profitability: $1M total profits, 13,000+ trades, position sizes up to $60K
- Use cases: arbitrage scanning, Polymarket automation, testnet "proof of activity" farming
- Monetization models: TA report subscriptions ($100-300/month), strategy services
- Critical: No key storage in agent; skill-based DeFi ops via BankrBot library

**Scalability Tiers Identified:**
1. Local: single agent on developer machine
2. Cloud Small: DigitalOcean App Platform, Linode g6-nanode-1
3. Enterprise Clustered: multi-server PostgreSQL + ClawDeck dashboard

- Natural language > pre-defined workflows (vs n8n's nodes)

- Persistent identity & memory edges toward proto-AGI capabilities
