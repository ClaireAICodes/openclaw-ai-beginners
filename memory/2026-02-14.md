# 2026-02-14 - Blog Platform Research & Shortlist

## Task
Deep dive research on popular blog platforms for automated content pipeline + shortlist recommendations.

## Platforms Researched
- WordPress.org (REST API)
- Ghost (Admin API + Content API)
- dev.to (Forem API v1)
- Hashnode (GraphQL API)
- Medium (Partner API, unofficial)
- Paragraph (TypeScript SDK + REST, alpha)

- Hive Blockchain (JSON-RPC)

- LinkedIn (Posts API v202606)
- X/Twitter (API v2)

## Shortlist Recommendations

### Tier 1 - Implement First
1. **Ghost (self-hosted)** - Core owned platform, full monetization control, excellent Admin API
2. **dev.to** - Massive dev audience, SEO power, simple API, traffic acquisition
3. **Paragraph** - Web3-native, token/coin integration, NFT project synergy

### Tier 2 - Add After Core
4. **Hashnode** - Developer docs support, GraphQL API, custom domains
5. **LinkedIn** - B2B audience, official API (requires company page)
6. **X (Twitter)** - Real-time distribution, thread format, API v2

### Excluded
- **Medium**: API limitations, paywall restrictions, Partner Program barriers
- **Substack**: No official API, newsletter-first (better as separate tool)
- **Mirror**: No REST API, manual process, save for special announcements only
- **WordPress**: Valid but Ghost provides superior editorial experience for pure blogging

## Publisher Agent Architecture (Planned)
```
Unified Interface → Platform Adapters
- Ghost Adapter (Admin API v5+)
- dev.to Adapter (Forem API v1)
- Paragraph Adapter (SDK)
- Hashnode Adapter (GraphQL)
- LinkedIn Adapter (v202606)
- X Adapter (v2)
```

Features: draft→publish, scheduling, image upload, tag mapping, SEO metadata, canonical URLs, error handling, webhook support.

## Analytics Integration
Track per-platform metrics, weekly reports (views, reactions, reads, conversions), feed back to Research agent for optimization.

## Strategic Rationale
Content pipeline follows "Owned + Community + Web3" model:
- Owned: Ghost (subscriptions, paywalls, full control)
- Community: dev.to (traffic), Hashnode (docs audience)
- Web3: Paragraph (tokenized engagement, NFT project alignment)

Monetization diversified: subscriptions, affiliate, tokenomics, potential ads (post-50k traffic).
