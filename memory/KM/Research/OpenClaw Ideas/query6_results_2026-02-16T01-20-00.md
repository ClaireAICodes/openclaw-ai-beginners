## Preliminary Insights
- **Crisis scale**: 7-12% of skills on ClawHub are malicious (Snyk: 7.1% of 3,984 = 283; Koi Security: 341 of 2,857)
- Attack vectors: fake tooling links, social engineering ("requires openclaw-core"), obfuscated RCE (base64 curl|bash), prompt injection, data exfiltration
- Real-world impact: thousands of downloads of malicious skills like "What Would Elon Do?" before takedown
- Supply chain is the new attack surface: third-party content fetch, remote installs from public registry create path for malware
- Defensive measures emerging: VirusTotal scanning integration, Koi Security's Clawdex scanner, Snyk vulnerability detection (W011, RCE indicators)
- Enterprise risk: healthcare deployments could trigger immediate HIPAA breach assessments if malicious skill accesses PHI
- User behavior: need for skill verification before install, treat ClawHub like npm/PyPI with same caution
- Response timeline: attacks ongoing as of Feb 2026, ecosystem scrambling to add scanning and review processes
