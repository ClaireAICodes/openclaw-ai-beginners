### 1. Smart Calendar Event Parser from Email HTML (GREEN)
**Impact:** High | **Effort:** ~10 hours | **Confidence:** High

**Overview:**
Automatically parses class/event info from Master's boss's HTML emails, extracts structured data, and creates calendar events or sends quick-approve Telegram notifications. Directly addresses USER.md automation target.

**Resource Requirements:**
- 🆓 OpenClaw cron for scheduled email checks
- 🆓 Microsoft 365 API (if configured) or IMAP access
- 🧰 OpenClaw skills: gog (Gmail/Calendar) if using Google, or custom M365 parser
- 💸 Costs: $0
- 🔑 Master must provide: Email account access (likely already configured), calendar write permissions

**Prerequisites:** Confirm email access method (Gmail vs M365)

**Feasibility:**
- ⚠️ Minor Master input needed: confirm which email/calendar system the boss uses, approve notification format

**Implementation Steps:**

1. **Setup Phase** (2 hours)
   - Identify email access: check if gog skill handles M365 or if custom IMAP needed
   - Define email patterns (sender, subject keywords) that indicate class schedule emails
   - Design notification format for Telegram approval flow

2. **Development Phase** (4 hours)
   - Build HTML parser module: extract dates, times, venue, class title, participants
   - Handle format variations (tables, divs, plain text within HTML)
   - Build normalization layer for date/time formats
   - Create Telegram approval message with pre-filled event details and one-tap buttons

3. **Testing Phase** (2 hours)
   - Feed parser 5-10 sample emails (Master can forward examples)
   - Validate extraction accuracy across format variations
   - Test Telegram approval flow end-to-end

4. **Deployment Phase** (2 hours)
   - Set up OpenClaw cron job: check inbox every 30 min during work hours
   - Deploy parser as workspace script
   - Configure fallback: low-confidence → forward to Master with "Needs review" flag

5. **Maintenance Phase** (ongoing)
   - Log parsing accuracy, learn from corrections
   - Monthly review of false positives/negatives

**Potential Blockers:**
- M365 API access may need admin approval from Master's org → fallback to IMAP
- Boss's HTML format may change → adaptive pattern matching + learning from corrections

**Success Criteria:**
- Captures ≥90% of class schedule emails correctly
- Reduces Master's calendar setup time from ~5 min/email to 10 seconds (approve tap)
- Zero missed classes due to parsing failures within first month
