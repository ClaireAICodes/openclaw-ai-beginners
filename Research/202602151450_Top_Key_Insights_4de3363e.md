- Session reset habit can save 40-60% costs
- Memory embedding cache (50k entries) recommended
- Smart model routing can cut API costs by 50-80%
- Use cheap coordinator models, expensive models for execution only

- ClawHub registry: 1,700+ community skills
- Skills follow Anthropic's Agent Skill convention
- Managed hosting now available (DigitalOcean App Platform)
- Enterprise features: container security, GitHub Actions/Zapier integrations
- Active multi-agent projects: clawe, mission-control, Crabwalk

**Security Considerations:**
- Full system access = high power but high risk
- Prompt-based guardrails can be overridden
- Containerization essential for blast radius limitation

- 3-layer skill system: Bundled → Local overrides → Workspace

- Canvas for UI operations, Nodes for hardware (camera, screen, location)
- Real-time streaming via WebSocket with partial filters
- Infrastructure tip: use tmux for long operations, web terminal for flaky SSH
