## Preliminary Insights
- Token optimization hierarchy: 1) Move static instructions to skills, 2) Local processing (Intel AI PC), 3) Smart model routing, 4) Context slimming
- Memory recall (memorySearch) vs data search (qmd) have different optimization profiles; semantic search can reduce lookup costs 90%
- Heartbeat routing through local models (Ollama) eliminates idle cloud costs ($2-5/day savings per instance)
- Dedicated Token Optimizer skill exists and is recommended by community forks
- Intel AI PC deployment shifts compute from cloud to edge, fundamentally changing cost structure
