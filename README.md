# OpenClaw & AI Agents — Beginner's Guide

A beautiful, beginner-friendly one-page website introducing OpenClaw and AI agents. Perfect for newcomers to AI automation who want to understand the platform and start building intelligent agents.

## Features

- Clean, modern gradient design with smooth animations
- Comprehensive beginner content covering:
  - What is OpenClaw?
  - What are AI agents?
  - Key concepts: Skills, Workflows, Automation, Memory
  - Practical use cases across multiple domains
  - Step-by-step getting started guide
- Fully responsive for mobile, tablet, and desktop
- No external dependencies — pure HTML/CSS/JS
- Educational focus with clear explanations and pro tips

## Quick Start

Simply open `index.html` in any modern browser. No build process required.

## Deploy

### GitHub Pages

1. Push this repository to GitHub
2. Go to repository Settings → Pages
3. Select "Deploy from a branch"
4. Choose `main` branch and `/root` folder
5. Save — your site will be live at `https://yourusername.github.io/openclaw-ai-beginners`

### Vercel / Netlify

- Import your GitHub repository
- Build command: leave empty (static site)
- Output directory: leave empty (root)
- Deploy
